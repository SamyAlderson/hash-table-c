# Hash Table C
A basic, lightweight hash table implementation in C

## What it does
This project implements a simple hash table in C, providing a basic key-value store for small-scale applications. It's a straightforward, no-frills implementation suitable for educational purposes or hobby projects.

## Install
Clone the repository with `git clone https://github.com/SamyAlderson/hash-table-c.git`, then navigate into the project directory with `cd hash-table-c`.

## Usage
To use the hash table, compile the `hash_table.c` file with `gcc hash_table.c -o hash_table`. You can then run the program with `./hash_table`. Consult the `hash_table.c` code for usage examples.

## Build from source
To build the project from source, run `make` in the project directory. This will compile the `hash_table.c` file and generate a binary.

## Run tests
This project does not include any unit tests. However, you can add your own test harness or framework to verify the hash table's functionality.

## Project structure
- `Makefile`: a basic makefile for building the project
- `hash_table.c`: the implementation of the hash table
- `README.md`: this file
